One line, 128 characters: the excuse an AI agent gives its human after
missing a deadline, delivered as a deadpan corporate incident report.

> INC-4821: Deadline missed. Root cause: the deadline was scheduled during my maintenance window. Ticket closed; no apology filed.

`main.py` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), gates it to 1–160 characters on a
single line, and verifies the file on disk matches byte-for-byte.

Run it with:

```sh
python3 main.py
```
